<img src="/wp-content/uploads/2018/03/SQLSat721_Speaking_250x250_01.png" class="size-full wp-image-775 alignleft" width="250" height="250" />I’m honored to have been selected to speak at [SQL Saturday Raleigh \#721 on April 14th](http://www.sqlsaturday.com/721/eventhome.aspx). I’m speaking about choosing the right high availability (HA) and/or disaster recovery (DR) solution for SQL Server. I’m given this talk just once before at the [Companero Conference](http://companeroconference.com) back in the fall of 2017. With the release of SQL Server 2017, there are few more HA/DR options that we have available to us. There are plenty of other [great sessions](http://www.sqlsaturday.com/721/Sessions/Schedule.aspx) being offered that day so it is not too late to sign up!

For those of you not familiar with [SQL Saturday events](http://www.sqlsaturday.com), they are organized by SQL Server professionals with help with sponsors and volunteers within the SQL Server community. Lunch is generally 10-15 dollars or you can choose to bring your own for an entire day of free training. There are multiple events every Saturday so find one near you!

I also signed up for Kalen Delaney’s ([b](http://sqlblog.com/blogs/kalen_delaney/)\|[t](https://twitter.com/sqlqueen)) pre-con on [SQL Server internals](https://www.eventbrite.com/e/sql-server-internals-for-performance-kalen-delaney-sql-saturday-raleigh-tickets-42773351245). I’ve always enjoyed digging into the internals of SQL Server. If you have a better understanding of what is under the covers it will help you build and support better solutions.

You’ll see me roaming the event with my camera so be sure and say hello and I hope to see you there!
